# sim-lib-view-worktable

`sim-lib-view-worktable` is the disposable, calm projection for an expedition
assembled from independently owned SIM organs. It presents semantic cards and
explicit route, device, attention, evidence, undo, export, and effect state. It
does not execute domain behavior or retain authoritative state.

Apply the same ordered `WorktableEdit` values to rebuild the same projection.
Deleting the projection is safe; its input edits and owner artifacts remain the
authority.
