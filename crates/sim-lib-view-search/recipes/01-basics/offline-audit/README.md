# Offline search audit

Construct `AuditRecords` from an existing `SearchRun`, capture,
representation, checked citations, receipts, and office anchors. Render with
`offline = true`, expand a result, and verify the Scene contains
`PROVIDER CLAIM — UNVERIFIED — NOT A CITATION`, a verified captured quotation,
the exact selector range, both content ids, and every policy/fidelity warning.

No step resolves DNS, opens a URI, loads media, or calls a provider.
